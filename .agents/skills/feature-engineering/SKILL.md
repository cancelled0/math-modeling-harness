# 特征工程与变量约简

目标是形成可复现、无泄漏且有证据支撑的特征规格。不要把原始字段修复、模型超参数调优或任意删参混为一谈。

## 前置条件

- 题目解析、Qx 目标、目标变量或输出定义已明确。
- `workspace/data/data_profile.json` 与需要的数据清洗结果可用；若数据未就绪，返回 `data-auditor-cleaner`。
- 训练/验证/测试或时间回测规则已定义。不能在全数据上拟合需要学习的转换后再划分。

## 五类操作

1. 原始字段修复：类型、单位、编码、缺失与异常处理，归 `data-auditor-cleaner`。
2. 衍生特征：滞后、滚动统计、交互、聚合、空间/网络特征等。
3. 指标构建：方向统一、标准化、权重或综合指数，并保留领域含义。
4. 模型特征选择：在训练折内选择预测变量，防止目标、时间和预处理泄漏。
5. 机理参数约简：依据可识别性、敏感性和物理含义合并或固定参数；不能把参数重要性等同于预测特征重要性。

## 工作流

1. 为每个候选特征记录来源字段、公式、单位、可获得时点、适用 Qx 与预期作用。
2. 先确定划分，再只在训练折拟合插补、缩放、编码、降维、筛选和目标相关转换；在验证/测试折仅执行 `transform`。
3. 选择与任务匹配的证据：
   - 共线性：相关结构、VIF 或条件数；
   - 泛化价值：交叉验证或滚动回测；
   - 重要性：置换重要性，模型验证后才可用 `shap`；
   - 必要性：同划分、同指标的消融实验；
   - 稳定性：跨折、跨种子、跨合理预处理方案的保留率与排名波动；
   - 机理参数：可识别性、单位一致性、灵敏度与校准不确定性。
4. 只有多项证据一致且性能、稳定性或解释负担确有改善时才删除变量。单次系数、单棵树重要性或单次 SHAP 排名不足以删变量。
5. 把最终转换封装为可复用流水线，并交给 `method-selector` 或 `model-code-analyzer`。
6. 若删除/保留决定影响最终结论，交给 `robustness-checker` 做消融与敏感性复核。

## 专业路由

- 通用监督/无监督流水线、交叉验证与调参：`scikit-learn`。
- 回归诊断、VIF、残差与计量特征：`statsmodels`。
- 已验证机器学习模型的归因：`shap`。
- 空间特征：`geopandas`；图结构特征：`networkx`。
- 时间滞后、滚动窗口和外生变量可用性：`forecasting-single-series`。
- 特征消融、参数敏感性与跨场景稳定性：`robustness-checker`。

## 规范输出

```text
workspace/features/Qx/qx_feature_spec.json
workspace/features/Qx/qx_feature_audit.json
```

`qx_feature_spec.json` 至少记录 schema_version、question_id、split_contract、target、features、transform_pipeline、fit_scope、units 和 output_columns。

`qx_feature_audit.json` 至少记录每个特征/参数的决定（keep/drop/conditional）、证据来源、折间稳定性、泄漏检查、消融结果、限制和复核状态。无法判断时用 `conditional`，不要编造通过结论。

## 规则

- 不修改或覆盖原始数据。
- 不使用测试集选择特征、阈值、窗口或超参数。
- 不将未来信息、赛后统计或目标派生信息泄漏到预测时点。
- 不因追求单一指标而删除领域关键变量。
- 不在没有可识别性证据时删除机理参数。
- 不替代 `method-selector` 选择最终算法。

## 验证

- 每个保留和删除决定均可追溯到公式、数据时点与实验证据。
- 所有有状态转换仅在训练数据上拟合。
- 消融比较使用相同数据、划分、单位与指标。
- 输出路径可被代码计划和鲁棒性检查直接引用。
