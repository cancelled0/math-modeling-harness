# 方法情景与 Skill 路由

先看任务要求的输出和约束，再看数据规模与风险；不要从熟悉的算法名称反推问题。表中的参考方案只在方法契约要求比较时执行，并须能完成真实任务和输出可比指标。

| 情景 | 识别信号 | 常用候选与参考 | 专业 Skill | 关键风险 |
|---|---|---|---|---|
| 评价、排名、综合指数 | 多指标、方向/权重、排序或分级 | 等权标准化基线；熵权/TOPSIS、PCA 辅助、灰色/模糊评价 | `method-selector`、`feature-engineering`、`statsmodels` | 指标冗余、权重支配、排名不稳、分数集中 |
| 单序列预测 | 单目标按时间排列、预测未来区间 | 季节朴素/末值；ETS、ARIMA/SARIMA、递归或直接回归 | `skforecast-recursive-direct`、`statsmodels`、`scikit-learn` | 随机划分、未来泄漏、短序列、区间覆盖不足 |
| 面板/计量/统计推断 | 估计效应、置信区间、组间差异、回归诊断 | 简单均值/线性模型；GLM、混合模型、面板或稳健回归 | `statistical-analysis`、`statsmodels` | 假设不满足、内生性、共线性、选择性报告 |
| 监督学习分类/回归 | 有标签、预测或判别 | 多数类/简单线性或逻辑回归；树、SVM、集成 | `scikit-learn`，验证后 `shap` | 类别不平衡、数据泄漏、过拟合、解释越界 |
| 聚类/分群 | 无标签、需要自然群体 | 简单规则/单一结构参考；k-means、层次、密度聚类 | `scikit-learn` | 任意簇数、尺度敏感、跨抽样不稳定 |
| LP/MILP/QP | 线性目标/约束、整数决策、资源分配 | 当前政策/可行贪心/松弛；LP、MILP、QP | `cuopt-numerical-optimization-formulation` | 漏约束、单位错、不可行、求解结果不可实施 |
| 非线性/动态优化 | 非线性机理、时序状态或控制 | 简化可行策略；NLP、动态规划、控制或启发式 | `method-selector`、`sympy` | 局部最优、边界条件、不可识别参数、计算预算 |
| 多目标优化 | 多个冲突目标、需要 Pareto 前沿 | 单目标加权/现行策略；NSGA-II/III、MOEA/D | `pymoo` | 目标尺度、约束处理、前沿解释、随机构成不稳 |
| 图、路径、网络 | 节点边、连通、流、匹配、路径 | 可行直接规则/最近邻；最短路、流、匹配、TSP/VRP | `networkx` | 边权不真实、业务约束遗漏、可行但不可执行 |
| 离散事件仿真 | 排队、资源、事件、等待时间 | 确定性近似；多重复 DES | `simpy` | 暖机期、重复数不足、分布假设、资源逻辑错误 |
| 机理/微分方程 | 守恒、传递、增长、状态方程 | 简化代数/差分模型；ODE/PDE/状态空间 | `sympy`、`statsmodels`、`pymc` | 单位与边界、参数不可识别、校准不确定性 |
| 贝叶斯/层次不确定性 | 小样本、多层结构、先验、后验区间 | 简单频率模型；层次贝叶斯、后验预测 | `pymc` | 先验敏感、收敛、可识别性、计算成本 |
| 空间分析 | 坐标、行政区、邻接、空间连接 | 非空间聚合基线；空间连接、缓冲、区域统计 | `geopandas` | CRS 错误、空间泄漏、尺度/边界效应 |
| 实验设计 | 数据尚未采集、需要处理组合和随机化 | 简单完全随机；区组、析因、响应面 | `experimental-design`、`statistical-power` | 混杂、功效不足、伪重复、不可执行设计 |
| 不确定性与量纲 | 测量误差、单位换算、误差传播 | 点估计参考；GUM/蒙特卡洛传播 | `uncertainty-and-units` | 维度不一致、相关误差遗漏、虚假精度 |

## 路由规则

- 混合题按子问拆分，每问可有一个主任务类型和必要的次任务类型。
- `method-selector` 负责角色化候选、参考策略和风险探针；专业 Skill 不替代人工方法选择。
- 无专门 Skill 的算法，由 `method-selector` 写清方法契约、假设、参考策略、指标和失败触发器，再交给 `model-code-analyzer` 与语言生成器实现。
- SHAP 是已验证模型的解释与审计工具，不是模型有效性的证据，也不是先验删变量器。
- 元启发式只有在精确/结构化方法不合适且有明确规模或非凸理由时进入候选；需要比较时保留可行参考并检查跨种子稳定性。
