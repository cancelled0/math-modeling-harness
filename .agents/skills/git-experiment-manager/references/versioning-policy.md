# 数模实验版本策略

## 稳定线与实验线

稳定线、后继实验、可比性和回退政策统一见 [项目 AGENTS.md](../../../../AGENTS.md)「Git 与算法实验」。分支名组件由工具转为小写，并将空格转成连字符。记录真实父提交；共同起点本身不证明实验可比。

## 提交边界

代码 checkpoint、执行收据和证据提交分别由工具保存；不要把先运行后补提交当成同一次可复现实验。失败尝试保留真实状态、日志和收据。

推荐前缀：`checkpoint`、`exp`、`fix`、`accept`、`revert`、`paper`、`audit`。

## 可比契约

至少一致：`question_id`、`data_hash`、`split_hash`、`feature_spec_hash`、`metric_definition_hash`。环境、依赖或随机种子不同必须显式显示；随机算法还应进行多种子或重复实验，而不是只比一个种子。

## 回退

使用项目 AGENTS.md 中的接受、拒绝或调整政策。切换前显式保存已归属当前任务的改动；存在无法归属的改动时报告阻塞，不自动 stash 或覆盖。
