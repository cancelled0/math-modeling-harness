# 科学图形专项支持

仅在图形编码、复杂多面板、不确定性、缺失数据或色觉可访问性需要专项判断时使用。

本 Skill 给出具体设计或审计建议，不另建竞争性的图表计划。用于正式结果展示的图形由 `modeling-results-presenter` 绑定数据来源和结论范围。

需要配色、出版规范、Matplotlib 示例或现有工具脚本时，读取 [详细指南](references/detailed-guide.md) 和相应参考文件。
